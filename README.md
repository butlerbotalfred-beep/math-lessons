# Math Lessons

Joshua's workbook math lessons for the iPad: each lesson's video with questions, the worksheet on screen, saved scores, and Steve, the boy hero who answers spoken questions.

- Site: plain HTML served by GitHub Pages from this branch. Open it in Safari on the iPad (Steve's listening only works in Safari, not from a Home Screen web app).
- Steve's answers: `supabase/functions/ask-pip` runs in the Supabase project `homeschool-pip` and calls Claude (Haiku). The Anthropic key is stored there as the `ANTHROPIC_API_KEY` secret and never sits in these pages.
- Scores are kept in the iPad's browser storage (`mathapp:pNN`).
- Steve's voice: the same Kokoro voice as the videos (60% "am_michael" + 40% "am_puck", stored as raw float32 in `voice/steve.bin`), made on the iPad by `voice/pip-voice-worker.js` (onnxruntime-web + espeak-ng phonemizer, int8 Kokoro model in `voice/`). Source is `tools/pip-voice-worker.src.js`; rebuild with `npx esbuild tools/pip-voice-worker.src.js --bundle --format=esm --minify --outfile=voice/pip-voice-worker.js` after `npm i onnxruntime-web phonemizer`. Fixed lines in `voice/lines/` were made with kokoro-onnx in Python. `coi-sw.js` is a small service worker that adds the COOP/COEP headers GitHub Pages lacks, so the voice can use several cores (about twice as fast). Fonts are self-hosted in `fonts/` because those headers block Google Fonts.
- Quiz answers: each page reads only the question (`pNN/audio/qN.mp3`); `app.js` makes the first tap on an answer play `pNN/audio/qN-oK.mp3` and the second tap choose it (`LessonApp.confirmChoices(card, qid)`).
- Walkable world (every lesson, `pNN/world.html`, which the home page opens): a 3D blocky path (`world/view3d.js`, three.js r160 self-hosted as `world/three.module.min.js`) seen from behind a block-built Steve. The lesson video is cut into one clip per question using the QUIZ cue times in the lesson's `index.html`; each clip grows out of a signpost and shrinks back into it after a right answer, coins (4, 3, 2 or 1 by try) land on the path, and Joshua holds the green Walk button so Steve walks to the next sign and picks them up. Each question card has "Look at the video" to see the paused picture and come back; a question the narrator just asked isn't read again unless "Hear it again" is tapped. Picture answers (bar graphs, tallies, dominoes, two-part boxes) are drawn by `world/world.js` from codes like `g:green,2`. Lesson logic is in `world/world.js`; spoken prompts are in `world/voice/`. Progress is saved under `mathapp:pNN:world`.
- The worksheet is the last stop: the printed page laid out by `world/kinds.js`. The app picks each box in order and one tap on a number answers it; wrong numbers turn red, the right one green (1 coin), and after 3 misses the answer goes in, in a green box with a red border, while its explanation plays. Each page's settings (worksheet parts, questions the narrator asks, picture answers) are in `tools/make_world_pages.py`, which writes the `world.html` pages. Spoken box questions and explanations: `node tools/ws_texts.js pNN > pNN.json && python3 tools/ws_voice.py pNN pNN.json` (writes `pNN/ws/`).
- Steve's Challenges (`challenges/`, linked from the home page): Joshua's assessment exams. `play.html?e=<id>` plays `challenges/exams/<id>.json` (question types: `tap`, `explain` = tap then tell Steve why, recorded; `read` = Joshua reads the words himself, recorded, and the words are never spoken). The first tap on an answer reads it, the second picks it; points are 4/3/2 by try, and after three misses Steve shows the answer (1 point). After 3 first-try misses in a row in one `ladder` (subject track), the rest of that track is skipped. Steve's lines are pre-made in his voice by `python3 tools/exam_voice.py [ids]` (writes `challenges/audio/` and `exams/<id>.audio.json`; needs `pip install kokoro-onnx soundfile` and the Kokoro files in `$KOKORO_DIR`). `exams/list.json` lists the 12 exams; `"ready": true` shows one on the hub. `?at=N` starts at question N (for testing).
- Challenge results: every answer and recording goes into an IndexedDB outbox on the iPad (`challenges/store.js`) and is sent to `supabase/functions/challenges` (tables `ch_sessions`, `ch_answers`, `ch_recordings`, `ch_writing`, `ch_parent`, RLS on with no policies; recordings in the private `challenge-recordings` bucket). `challenges/grownups.html` needs the grown-ups code (chosen on first visit, stored only as a salted hash; 8 wrong tries locks it for 15 minutes) and shows results by subject, recordings to play and mark word by word, each challenge's answers, and the paper writing task card.
